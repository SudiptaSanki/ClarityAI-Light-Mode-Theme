ClarityAI Extension - Test & Verification Page

About This Test Environment

This page is configured for verifying the capabilities of the ClarityAI browser extension. The extension is equipped with universal multi-provider connectivity, enabling analysis with Google Gemini, OpenRouter (including 100% free models), Groq, OpenAI, Claude, DeepSeek, and local Ollama instances.

This test text includes multiple sections and concepts to test text extraction, prompt synthesis, consultation breakdown, and document PDF generation.

Key Features to Test

Multi-Provider

Universal Model Support: Test switching between free OpenRouter models, Groq Llama 3.3, and Google Gemini without hardcoded limitations.

Consultation

Modes & Q&A: Try Quick Summary, Deep-Dive Consultation, Action Items, or ask a specific question in the query bar.

Selection

Selective Highlight: Highlight any paragraph on this page and run ClarityAI. Verify it analyzes only the selected text.

Export

Export to PDF: Click "Export PDF" in the popup toolbar to generate a clean, printable consultation report.

Technical Architecture Details

The ClarityAI architecture uses Manifest V3 with a dedicated module service worker, custom DOM tree-walker extractor, and an in-memory client engine supporting native Google Gemini REST, Anthropic Messages API, and OpenAI-compatible API endpoints. User keys are encrypted in local storage, and all inference requests are dispatched client-side with zero intermediary servers.

Verification Checklist

  1. Open the ClarityAI popup on this tab.
  2. Verify the active model badge displays in the header.
  3. Click Analyze Page to generate a consultation.
  4. Click Copy and paste into a text editor to verify formatting.
  5. Click Export PDF to test the printable report view.
